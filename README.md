Platinum Atlas — an offline guide and tracker for all 55 GTA VI PlayStation 5 trophies: official names, descriptions and grades, a checklist saved in the browser with export and import, kind and grade filters, a spoiler setting that hides story trophies until earned, a six-stage roadmap to the platinum, 18 missable trophies flagged, and a cited guide for every trophy.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide works offline, with the network off.
